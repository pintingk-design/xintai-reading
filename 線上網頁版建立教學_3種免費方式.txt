【國語文朗讀自主練習系統 - 線上網頁版建立與全班免安裝使用教學】

尊敬的郭老師：
若您希望讓全班 13 位學生或家長在家中、教室平板、iPad、Chromebook 或手機上「免安裝、直接用網址連結開啟」使用，建議使用以下三種最推薦的免費線上發布方式：

======================================================================
🏆 方式一：使用「Google 協作平台（Google Sites）」（新北市教育局帳號最推薦！）
======================================================================
因為新北市老師與學生都擁有教育局 Google 帳號（@ntpc.edu.tw），這是最官方、最安全且完全整合的方式：
1. 用電腦開啟 Google 協作平台：https://sites.google.com/new
2. 點擊右側選單的「插入」➔ 選擇「嵌入」（圖示為 </>）。
3. 點選「嵌入程式碼」分頁。
4. 將「index.html」檔案用記事本打開，複製裡面的全部內容，貼入框內，點擊「下一步」➔「插入」。
5. 將嵌入的區塊拉伸調整至全螢幕寬度與適當高度。
6. 點擊右上角藍色的「發布」按鈕，設定一個簡單網址（例如：xintai-reading）。
7. 發布完成！您將獲得一個專屬的官方 HTTPS 網址（例如：https://sites.google.com/view/xintai-reading）。
優點：
✓ 學生在任何平板或手機打開網址，完全不需要下載任何檔案！
✓ 符合 Google 安全協定，麥克風錄音與 Web Speech API 語音即時自動打字 100% 正常運作！

======================================================================
⚡ 方式二：使用 Netlify Drop（1 秒拖曳、免寫程式碼、最快速！）
======================================================================
1. 用電腦瀏覽器打開免費靜態託管頁面：https://app.netlify.com/drop
2. 將包含「index.html」的資料夾，直接用滑鼠拖入瀏覽器中。
3. 系統會在 10 秒內自動為您生成一個永久有效的全球 HTTPS 專屬網址（例如：https://xxxx.netlify.app）！
4. 您還可以在後台自行修改網址名稱（例如改為 xintai-reading.netlify.app）。
優點：
✓ 全自動即時上線，支援所有手機、平板、電腦！
✓ 自動啟用 SSL/HTTPS，語音即時辨識與示範朗讀逐字變色完全支援！

======================================================================
🐙 方式三：使用 GitHub Pages（軟體託管、永久免費）
======================================================================
1. 登入 GitHub（https://github.com/），新建一個公開倉庫（Repository）。
2. 將「index.html」上傳至該倉庫。
3. 點擊該倉庫的 Settings ➔ 找到左側的「Pages」。
4. 在 Branch 選擇「main」或「master」，點擊「Save」。
5. 數秒後即可獲得永久免費的專屬網址：https://[您的帳號].github.io/[倉庫名稱]/。

======================================================================
📱 手機/平板 App 化小技巧（PWA 加入主畫面）：
======================================================================
學生用手機或 iPad 打開網址後：
- 蘋果 iOS / iPadOS（Safari）：點擊螢幕下方「分享」按鈕 ➔ 選擇「加入主畫面」。
- 安卓 Android（Chrome）：點擊右上角三個點選單 ➔ 選擇「安裝應用程式」或「加到主畫面」。
這樣平板桌面上就會出現專屬的「國語朗讀自主練習」App 圖示，點開就是全螢幕沉浸式練習體驗！
