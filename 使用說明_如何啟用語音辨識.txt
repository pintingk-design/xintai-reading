【五年甲班 國語文朗讀自主練習系統】語音辨識與操作說明

一、為什麼直接雙擊 HTML 檔案時，不會自動打出我唸的字？
這是因為 Google Chrome 與現代瀏覽器的「網路安全性協定」限制：
當網頁網址開頭為「file:///」時，瀏覽器會基於安全考量，全面封鎖 Web Speech API（雲端語音轉文字伺服器連線）。
在此模式下，麥克風錄音（音訊儲存與波形顯示）完全正常，但無法全自動將語音轉為文字。

二、兩種最佳解決方案：

【方法 A：一鍵以本機伺服器啟動（最推薦，100% 啟用自動辨識）】
1. 將本壓縮包完整解壓縮到電腦資料夾。
2. Windows 使用者：直接雙擊點開「啟動朗讀軟體(Windows點我).bat」。
   Mac 使用者：直接點開「啟動朗讀軟體(Mac點我).command」。
3. 瀏覽器將自動開啟 http://localhost:8000/index.html。
4. 點擊開始錄音時，只要對著麥克風朗讀，系統就會即時把您說的話自動打成文字，並進行全自動逐字對齊比對！

【方法 B：直接開啟 HTML 檔案使用（免安裝任何軟體）】
若電腦未安裝 Python 或無法執行腳本：
1. 直接用 Chrome 開啟「國語文朗讀自主練習_逐字辨識完全修復版.html」。
2. 點擊「開始錄音」朗讀，唸完後點擊「完成錄音」。
3. 錄音完成後，畫面會直接出現【實際唸讀文字確認】輸入框。
4. 系統會貼心提供「帶入課文快速校對」按鈕，您可以直接檢查文字，或故意改動錯字（如把「晨光」改成「成光」），再點擊【送出評分】。
5. 系統會立即根據您確認的字詞進行【Needleman-Wunsch 雙序列逐字對照】與【扣分診斷】！

三、線上部署（供全班學生手機/平板使用）：
若要讓全班 13 位學生在家中或教室平板直接使用：
只需將本網頁 index.html 上傳至免費的 GitHub Pages、Vercel 或學校的 HTTPS 網站空間，
所有支援的裝置（平板、手機、電腦）打開網址即可免安裝自動啟用麥克風即時語音轉文字！
